# Privacy Policy - LinkedIn Notes Overlay

Public privacy policy for the LinkedIn Notes Overlay Chrome extension.

## Overview

This repository hosts the privacy policy for the **LinkedIn Notes Overlay** Chrome extension, published on the Chrome Web Store.

The policy is automatically served via GitHub Pages at:
`https://microsaasandco.github.io/privacy-policy/`

## About LinkedIn Notes Overlay

- **Purpose**: Create and store private notes locally on LinkedIn pages
- **Data Storage**: Local browser storage only (chrome.storage.local)
- **No Server Communication**: Zero external API calls
- **No Tracking**: No analytics, cookies, or telemetry

## Privacy Policy

Read the full policy: [index.html](index.html)

## Key Points

✅ All data stored locally on user's device  
✅ No data sharing with LinkedIn, Google, or third parties  
✅ No external servers or cloud storage  
✅ Users can delete notes anytime  
✅ Easy export/import for backup
